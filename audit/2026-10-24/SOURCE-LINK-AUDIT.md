**Every link was checked at its destination, not just as a URL.** The checks ran in Chrome on the owner's Mac on October 24, 2026, from 9 p.m. Pacific:
- **PDFs.** Each was downloaded on its own site, its PDF header was checked, and its text was read with pdf.js. The text had to name the right proposition and, where relevant, include the arguments.
- **Official HTML pages.** Each was fetched and parsed. The page title and main text had to name the right proposition, and argument pages had to contain the arguments.
- **Independent pages.** Each was opened and read.
- **Visual checks.** The LAO, legal text and NACHC PDFs were opened and confirmed to display in the Chrome PDF viewer. LAO Prop 1 was opened by clicking it from the deployed tool.

## Root cause of the blank pages

No link was broken, and a blank page could not be reproduced in Chrome on a Mac. Every PDF is a valid file with real text, and every server returned the document.

The likely cause is the browser, not the links. Four things point that way:
- **Most of these sources are PDFs.** 37 of the 68 links open a PDF directly.
- **Some browsers show a blank page for PDFs.** In-app browsers (Reddit, Instagram, Messages previews), some Android browsers, and Chrome while a large PDF is still downloading can all do this.
- **LAO pages are served through Cloudflare.** Cloudflare can show a check page first. The LAO folder address returned "403 Forbidden" in this test, although every LAO PDF loaded.
- **Four addresses redirected.** They still worked, but a redirect adds a step before the page shows.

**What changed** (data and display only; no rating, reason, weight or scoring logic changed):
- **LAO analysis (14).** The link now opens the same analysis on the official voter guide in HTML (`/propositions/N/analysis.htm`). A small "LAO PDF" link beside it keeps the LAO's own PDF.
- **Official arguments (6: Props 38, 39, 40, 42, 44, 45).** The link now opens the official HTML arguments page. A "Full section PDF" link keeps the printed section.
- **Redirecting addresses (4).** Two Hoover pages, the League of Women Voters page and one CalMatters article now link their final addresses.
- **New-tab links.** Every source link in the tool now uses `rel="noopener noreferrer"`.
- **Unchanged.** Legal text has no official HTML version, so those links stay PDFs. All source numbers, such as [1] and [3] next to each rating, still point to the same source.

## Still needs a person

- **HousingWire (Prop 45, source 5).** The free part shows a summary of Prop 45; the full article needs a free account. The label says it covers "the Hernandez CEQA study", which could not be confirmed in the free part. The study itself is source 7 (Holland & Knight), which does load.
- **Props 37 and 41** have no "Official arguments" link. Prop 41 links the official title, summary and analysis. Both have official argument pages, but no source was added in this pass.

## Repeatable check

`node tools/check-source-links.mjs` checks every source and alternate link in the tool and fails on any problem: a broken status, a non-PDF file served as a PDF, a near-empty page, or an official page that does not name its proposition. It also lists redirects. Run it on a computer with internet access before each release. This cloud workspace blocks those sites, so it could not run the script here. The browser test suite now also checks every source link offline: https only, safe new-tab attributes, HTML first for LAO analyses and official arguments, and no known redirecting addresses.
